# Spring start-up / de-winterizing

**Symptom:** First start after storage.

## Safe owner checks & fixes
1. Inspect fuel lines, bulb, clamps for cracks; replace hardened lines.
2. Check fuel for water; use fresh fuel.
3. Charge battery; clean terminals.
4. Install fresh plugs if fogged/fouled.
5. Check gear lube level.
6. Start on muffs/in water only; confirm telltale stream immediately.
7. Expect smoke briefly if fogged.

## Parts / tools
Charger, plugs, flush muffs, fresh fuel.

## Call a marine mechanic when
No telltale on first start; won't start after fresh fuel and plugs; leaks or cracked hoses beyond simple replacement. If you're on the water and unsafe, call TowBoatUS/Sea Tow or the Coast Guard (VHF 16).
