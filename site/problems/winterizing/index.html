How do I winterize an outboard motor?

Winterizing an outboard · Symptom: Preparing for storage / freezing temps.

Quick answer: Start here: Stabilize fuel and run in water so it circulates (Honda: ~10 min). If that doesn't fix it, work through the checks below, and see a marine mechanic if you're unsure.

Safe owner checks & fixes

  1. Stabilize fuel and run in water so it circulates (Honda: ~10 min).
  2. Flush cooling system with fresh water.
  3. Change engine oil (4-stroke) and gear lube; milky lube = water intrusion → dealer pressure test.
  4. Pull prop, remove fishing line from shaft, grease shaft.
  5. Fog cylinders per manual.
  6. Disconnect/charge battery.
  7. Store motor vertical/tilted down so water drains.

Parts / tools

Flush muffs, fogging oil, gear lube pump & lube, oil/filter, stabilizer, grease, prop wrench.

Call a marine mechanic when

Gear lube is milky (pressure test); you can't fog or drain per manual; 4-strokes with exposed timing belts if unsure; any leaks found. If you're on the water and unsafe, call TowBoatUS/Sea Tow or the Coast Guard (VHF 16).
